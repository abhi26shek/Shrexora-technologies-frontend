# Shrexora Technologies — Exact Frontend Website Code

Ye folder aapki finalized **Shrexora Technologies** website (`shrexora_technologies_app.jsx`) ka **100% Exact Frontend Code** hai (jisme fit-to-screen layout, cleaned headings without '3D'/'6', full-bleed square app icons, 3D rotating smartphone, live mobile sample websites inside phone, 6 Growth Lab tools, aur SHREX-AI 2.0 Chatbot included hain).

## Tareeka 1: VS Code / Terminal Mein React + Vite Chalaayein
Bilkul standard React + Vite project ki tarah seedha isi folder mein terminal khol kar run karein:
```bash
npm install
npm run dev
```
Aur browser mein **`http://localhost:5173`** kholein.

## Tareeka 2: Bina `npm install` Ke Direct Browser / Google Sites Mein Kholein
Is folder mein **`OPEN_IN_BROWSER_DIRECTLY.html`** par double-click karein (ya iska code Google Sites ke Embed Code mein paste karein)—puri website bina kisi server ke 100% same dikhegi aur saare buttons kaam karenge!
